# Welsh (Cymraeg) Language Pack for AnySoftKeyboard

A Welsh language pack for [AnySoftKeyboard](https://github.com/AnySoftKeyboard/AnySoftKeyboard):
QWERTY layout with the full Welsh alphabet (including ŵ and ŷ), a dictionary
built from Welsh Wikipedia text, and a hand-tuned **spoken-Welsh layer** that
fixes the pack's mutation and contraction suggestions.

## The spoken layer (why this fork exists)

The stock dictionary build scales corpus word counts linearly (top word =
frequency 64), which squashes everyday Welsh into the noise floor — and a
Wikipedia corpus barely contains spoken constructions at all. In the first
build, *fy nghath* ("my cat") was never suggested, autocorrect tried to turn
it into a place name, *mawr* was buried, and a phantom contraction "dwi'm"
outranked the real "dwi'n".

The fix lives in `welsh/pack/dictionary/prebuilt/welsh_spoken.xml`: 517
entries with hand-set frequencies, merged over the corpus dictionary. It
covers:

- Core contractions and function words (*dwi'n*, *mae'n*, *rwy'n*, …)
- The full mutation paradigms (soft / nasal / aspirate) for ~120 common
  nouns — *cath → gath / nghath / chath* — generated by the deterministic
  Welsh mutation rules
- Everyday adjectives with their predicative soft forms (*mawr → fawr*,
  *bach → fach*, …)
- Place-name forms (*Cymru → Gymru / Nghymru*, *Bangor → Fangor / Mangor*, …)

The wordlist is generated by `welsh/generate_spoken_wordlist.py` — rerun it
to regenerate the XML after editing the vocabulary.

## Install (prebuilt APK)

Grab the APK from this repo's Releases and install it alongside
AnySoftKeyboard. The release builds are **debug-signed**: fine for
sideloading, and future updates must come from builds signed with the same
key (i.e. releases from this repo).

Then enable the Welsh pack inside AnySoftKeyboard's language settings.

## Build it yourself

1. Clone AnySoftKeyboard.
2. Copy the `welsh/` folder from this repo to `addons/languages/welsh`.
3. Add to the ASK root `settings.gradle`:
   `include ':addons:languages:welsh:pack', ':addons:languages:welsh:apk'`
4. Build (JDK 21):
   `./gradlew :addons:languages:welsh:apk:assembleDebug`

The dictionary is regenerated during the build from the text corpus in
`welsh/pack/dictionary/inputs/` merged with the prebuilt spoken layer.
(The corpus sample used for the release build is not tracked in this
repo — see `welsh/pack/dictionary/inputs/README.txt`.)
